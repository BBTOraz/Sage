Разберите простой поиск

Программа сравнивает слова вопроса со словами в каждом документе.

Главная идеябез библиотек
def search_documents(query):
    query_words = words(query)
    ranked = []

    for document in DOCUMENTS:
        common = query_words & words(document["text"])
        if common:
            ranked.append((len(common), document))

    ranked.sort(reverse=True, key=lambda item: item[0])
    return [document for _, document in ranked[:3]]
Почему это хороший старт

Алгоритм понятен, работает без интернета и легко проверяется глазами.

Чего он пока не умеет

Он плохо понимает синонимы. Позже его можно заменить поиском по смыслу.

Практика 02

Добавляем один безопасный инструмент

Раньше поиск запускался всегда. Теперь система сначала решает: нужен ли поиск для этого сообщения, и только затем просит программу его выполнить.

Начинаем с обычного смысла

Инструмент — это подписанная функция

У неё есть понятное имя, описание, входные данные и результат. Модель видит эту «инструкцию к кнопке» и может попросить программу нажать её.

Главное правило: модель не читает файлы напрямую и не запускает функцию сама. Она лишь формирует просьбу. Обычный код проверяет её и выполняет разрешённое действие.
search_documents

Паспорт инструмента

Модель должна понимать, что ей разрешено

Чем точнее описание, тем меньше случайных вызовов и неверных аргументов.

Пишем безопасную оболочку

Сначала проверка, потом поиск

Инструмент принимает не путь к файлу, а только короткий вопрос. Список документов остаётся внутри программы.

search_documents_toolпонятный результат
def search_documents_tool(query: str) -> dict:
    query = query.strip()

    if not query or len(query) > 300:
        return {
            "status": "invalid_input",
            "items": []
        }

    items = search_documents(query)

    if not items:
        return {
            "status": "not_found",
            "items": []
        }

    return {
        "status": "ok",
        "items": items[:3]
    }
Вход ограничен

Пустая строка и слишком длинный запрос не доходят до поиска.

Путь скрыт

Модель не может написать ../../secret.txt. Она передаёт только вопрос.

Результат имеет форму

Программа всегда возвращает один из трёх статусов: найдено, не найдено или неверный ввод.

Количество ограничено

Даже если совпадений много, модель получает не больше трёх фрагментов.
